# Знаток Улетай — иллюстрации

50 локальных WebP (`01`–`50`) соответствуют полю `art` вопросов
из `src/data/uletayQuiz.ts`. `51.webp` — трофей победителя,
`hero.webp` — обложка. Все предметы и персонажи имеют прозрачный альфа-канал;
обложка имеет собственный фон.

Изображения созданы ImageGen 25.11.2026. Предметные иллюстрации выдержаны
в тёплой золотистой палитре с фактурой бумаги и металла. Для вопросов
о личностях используются рисованные портреты музыкантов:

Референс Кулясова: официальный сайт https://animaciya.online/,
https://static.tildacdn.com/tild3831-3736-4664-b666-633735306132/rock.png.
Референс Шклярского: фото группы из существующей базы приложения,
`uploads/images/пикник-31f4511f6bcd.webp` (второй слева).
Остальные портреты — стилизованные интерпретации внешности публичных артистов.
Фотографии в игру не включены. Все девять портретов дополнительно
перерисованы по одному на отдельных прозрачных холстах, чтобы исключить
фрагменты соседних ячеек. При упаковке используются поля `portraits`
манифеста вместо нарезки исходного листа для этих вопросов.

`scripts/prepare-quiz-art.mjs` упаковывает подготовленные прозрачные листы
3×3, нарезает ячейки и сохраняет альфа-канал. Манифест исходников передаётся
первым аргументом; оригиналы генераций остаются в каталоге ImageGen.

В интерфейсе `QuizIllustration` окрашивает альфа-силуэт, после ответа
анимирует появление цветной иллюстрации. Название предмета и имя персонажа
не доступны читателю экрана до раскрытия. Изображения включены в пакет
приложения и не зависят от запросов к внешнему серверу.
