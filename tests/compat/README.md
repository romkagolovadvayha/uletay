# Контракт выпущенных мобильных клиентов

`app-data-validation-1.0.15.ts.txt` — неизменённый исходник валидатора из сохранённого выпуска 1.0.15. Он совпадает с валидатором выпуска 1.0.16. Файл хранится как текст, чтобы исторический импорт типов не связывался с текущим приложением; тест компилирует только его собственный код. Это исходник проекта, без зависимостей и ключей.

Не заменяйте этот файл текущей реализацией при изменениях API: он защищает контракт уже установленных приложений. Новые данные должны проходить старую проверку. Для несовместимого формата потребуется отдельная версия API с сохранением старого endpoint.

Запуск: `npm run test:compat`. Для проверки локальной CMS и всех изображений, на которые ссылается её публичный каталог, задайте `TEST_API_ORIGIN=http://localhost:3107`. HTTP-тест ничего не записывает и не отправляет уведомления.

Исходники 1.0.12 из Git и сохранённые полные снимки 1.0.15/1.0.16 отдельно использовались для запуска настоящих старых функций загрузки, нормализации, кеширования и чтения радио против новой локальной CMS. Это проверка JavaScript-контракта; она не заменяет запуск установленных APK на телефоне. Результаты: `docs/COMPATIBILITY.md`.
