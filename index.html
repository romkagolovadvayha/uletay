SSH-ключ для CI

Скрипт deploy/print-github-ssh-key.sh:

ssh-keygen -t ed25519 -f ~/.ssh/uletay_ci -N "" -C "github-actions"
cat ~/.ssh/uletay_ci.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

B64=$(base64 -w0 ~/.ssh/uletay_ci)
echo "$B64" | base64 -d > /tmp/t && chmod 600 /tmp/t && ssh-keygen -y -f /tmp/t
# → в GitHub Secret SSH_PRIVATE_KEY_B64

Не клади приватный ключ в Variables — только Secrets. Ключ без пароля.

Деплой на сервере (deploy/remote-deploy.sh)

# cms/.env на сервере
DB_HOST=...
CORS_ORIGIN=https://DOMAIN
UPLOAD_DIR=/var/www/uletay/uploads
PORT=3000

npm ci
npm run db:install          # tsx scripts/install.ts → schema + seed

pm2 start /var/www/uletay/cms/.next/standalone/server.js \
  --name uletay-cms \
  --cwd /var/www/uletay/cms \
  --update-env

certbot --nginx -d DOMAIN   # если сертификата ещё нет

CMS собирается в GitHub Actions (npm run build --prefix cms), на сервер уходит готовый cms/.next.

Локальная разработка

npm install && npm install --prefix cms

# терминал 1

npm run web
