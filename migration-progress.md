# Нативный интерфейс приложения

Уточнённое требование пользователя: Android/iOS работают на React Native без WebView/Expo DOM для интерфейса. Новый веб-дизайн переносится в нативные компоненты. Веб сохраняет текущую работу и SEO. Только локальная тестовая сборка, без публикации.

- [x] Отменена оболочка Expo DOM; возвращён React Native корень с существующей навигацией и нативными сервисами.
- [x] Нативные шрифты, стекло, меню с вырезом, карточки, сердечки и шторки.
- [x] Нативные главная, лайн-ап и карточка артиста с новым дизайном. Видео переведено на стабильный SurfaceView, таймер изолирован от видео.
- [x] Нативные чат и пожелания с действующим API, ответами и голосами; гостевые действия показывают VK-вход.
- [x] Расписание, избранное, правила, карта и настройки приведены к новому стилю. Существующие помощь/еда сохранены; не каждый их маршрут повторно пройден вручную.
- [x] Сохранены API с резервным адресом, push, локальные напоминания, системное «Поделиться», внешние ссылки, Android Back. Отдельные пределы проверки — в отчёте.
- [x] Сохранение настроек и избранного между запусками, скрытые кнопки скачивания внутри приложения.
- [x] Проверка именно нового интерфейса в Android, получение push в открытом/свёрнутом/закрытом состоянии и переход в новую карточку. После удаления из recents подтверждено отсутствие процесса до push и его запуск по нажатию.
- [x] Android VK ID SDK подключён к клиенту 54911793 отдельно от веб-клиента; без phone scope. PKCE, одноразовость, сессия и manifest проверены.
- [ ] Фактический вход реальным аккаунтом через установленный VK: в эмуляторе VK нет, кабинет VK ID заблокирован политикой браузера. iOS и RuStore push также не проверены.

Backend и база остаются в существующем CMS/API. Тесты используют `uletay_web_design:3352`, API `http://192.168.1.130:4174/api`. Старые нативные экраны не являются эталоном нового дизайна.
