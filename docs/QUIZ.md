# Знаток Улетай

Экран доступен через «Ещё → Знаток Улетай», боковое меню и `/quiz`.
Встроен в существующий More stack, доступен вне дат фестиваля.

В базе 50 фиксированных вопросов. В новом раунде выбираются 4 случайных
вопроса каждого из трёх уровней; повторов внутри раунда нет. Неоткрытые
вопросы имеют приоритет. Варианты ответа перемешиваются независимо.
Правильный ответ в редакционной записи `answers` всегда первый;
движок преобразует его в случайный экранный индекс.

Для победы нужны 12 верных ответов подряд. Ошибка завершает раунд после
показа объяснения. Очки остаются внутренней частью статистики;
на игровом экране показывается только прохождение 12 вопросов.
Результаты сохраняются локально; денежных ставок или призов нет.

Подсказки доступны по одному разу: 50:50 исключает два неверных ответа;
наводка показывает редакционную подсказку; замена выбирает другой вопрос
того же уровня и исключает все вопросы текущего раунда и уже показанные.
Ответ принимается одним нажатием, сразу блокируется; повторное нажатие
не меняет выбор и не начисляет очки.
Время ответа не ограничено.

Рекорд, победы, число игр и открытые вопросы хранятся в AsyncStorage
под ключом `uletay:quiz:v1`. При недоступном хранилище можно играть с
результатами в памяти сессии. Текущий незаконченный раунд не сохраняется
при перезагрузке или размонтировании экрана. Сервер и авторизация не нужны.

Игра занимает доступный экран без прокрутки. Навигационная панель приложения
сохраняется на игровом экране; контент учитывает её высоту. Крестик возвращает
на главную. На входе по центру
расположены название, короткий текст о квизе и кнопка «Начать», без иллюстрации.
Для вопроса и ответов используются рисованные
векторные рамки с острыми концами, двойной металлической обводкой и цветовым
выделением результата. Иллюстрация адаптируется к оставшейся высоте; на
широком или горизонтальном экране переносится в отдельную колонку.

Клавиатура: 1–4 сразу отвечают.
Варианты всегда расположены 2×2: A/B сверху, C/D снизу. После раскрытия
через 2,6 секунды автоматически открывается следующий вопрос или результат.
Каждый верный ответ сопровождается золотой вспышкой, разлетающимися искрами
и крупной отметкой «Верно!» поверх иллюстрации. При снижении движения
показывается статичная отметка без вспышки и частиц.
Стандартные кнопки также доступны через Tab/Enter/Space.
Снижение движения в системных настройках отключает плавающие иллюстрации,
частицы и переходы. Тактильный отклик включён для ответов на iOS.

Факты сверены с базой 240 артистов `cms/seed/content.json`, официальным
архивом фестиваля, сайтами артистов и Last.fm. Ссылка конкретного факта
сохранена в записи вопроса; после ответа показано объяснение без дополнительных
кнопок. Для 2020/2021
используется вопрос о переносе: анонсированный состав 2020 года не
называется состоявшимся концертом. Даты проверки — 25.11.2026.

Проверки: `npm run test:quiz`, `npm run typecheck`, `npm run lint`,
`npm run build:web`. Тест игры проверяет данные и локальные изображения,
согласованность лет с базой, уникальность и сложность раунда, подсказки,
блокировку ответа, победу, поражения на несгораемых ступенях и хранилище.
