# API приложения

Базовый URL: `https://<домен>/api`. Все секреты находятся на сервере. Публичное приложение читает данные без административного токена.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/health` | Проверка сервера и подключения к БД |
| GET | `/data` | Содержимое фестиваля; ETag и условное чтение поддерживаются |
| POST | `/auth` | Вход по логину/паролю, Bearer-токен на семь дней |
| PUT | `/data` | Сохранение полного контента, требуется Bearer-токен и актуальная ревизия |
| POST | `/upload` | Загрузка изображения, Bearer-токен либо активная сессия с тем же Origin |
| GET | `/uploads/<путь>` | Изображения редакторов |
| GET | `/fest-assets/<путь>` | Публичные изображения из `assets` |
| GET | `/radio/now-playing` | Метаданные радио |
| GET | `/route` | Внешние маршруты |
| POST | `/push/subscribe` | Подписка устройства, обновление параметров и избранного |

Вход:

```json
{ "username": "admin", "password": "пароль владельца" }
```

Ответ `/auth`: `{ "token": "..." }`. Для защищённых запросов передавайте `Authorization: Bearer <token>`. Токен и cookie не добавляются к публичным URL. Просроченная либо отозванная сессия возвращает 401. Ограничение попыток входа — 429.

Перед записью прочитайте `/data` и передайте полученную `revision` вместе с изменённым документом. При конфликте вернётся 409: перечитайте данные и объедините изменения. Не повторяйте запись старого документа автоматически.

`POST /upload`: `multipart/form-data`, поля `file`, необязательные `subdir`, `preset`; для схемы карты — `kind=map`. Изображения преобразуются на сервере. Обычный ответ: `{ "url": "/api/uploads/images/..." }`.

Типы: `cms/src/types.ts`, клиентские типы: `src/types`. Общая валидация: `shared/app-data-validation.ts`. Конкретные ограничения полей и допустимые форматы запросов находятся рядом с обработчиками в `cms/src/app/api` и `cms/src/lib`.

Для браузерных помощников приложение регистрирует шесть инструментов WebMCP только для чтения публичных данных. Обнаружение: `/llms.txt`, `/.well-known/ai-catalog.json` и `/webmcp.json`. Это браузерная интеграция; HTTP endpoint вызова MCP отсутствует. [Схемы, ограничения и тестирование](AI-DISCOVERY.md).
