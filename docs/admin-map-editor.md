# Редактор карты

Админка использует MapLibre GL JS той же версии, что публичная веб-карта. `AdminMapCanvas` импортирует `map-style`, `map-scene`, `web-map-scene` и загрузчик из `src/components/map`. Типы карты также общие. Стили дорог, физические подписи, 3D-здания, изображения и ограждения не нужно поддерживать отдельно для CMS.

В 2D поверх публичной сцены добавляются только инструменты редактора: выделение, вершины, вход и служебные линии. Режим 3D скрывает эти инструменты. Зоны, дорожки и POI имеют общую историю и сохраняются одной серверной операцией с проверкой ревизии. Перемещение группы учитывает дочерние места, части полигонов и связанные POI. Поворот не заменяет исходную форму прямоугольником.

Проверка навигации вызывает тот же `findInternalPathAsync`, что приложение. Географические вычисления вынесены в `geo-math`, чтобы CMS не загружала React Native или внешние маршрутизаторы. Неиспользуемый обход разрывов через внешний сервис удалён; маршруты остаются строго внутри доступной сети.

При выделении здания, зоны или дорожки над её центром появляются кнопки ↶ / ↷: поворот на 5° в обе стороны. Панель следует за объектом при перемещении карты и сохраняет фокус после нажатия. Поворот группы включает её дочерние объекты и связанные входы; каждое нажатие можно отменить или повторить. В режиме рисования, выбора входа и гостевом 3D панель скрыта. У точечного POI ориентации нет, поэтому кнопки не показываются.

## Запуск и проверка

`npm run dev --prefix cms` и `npm run cms:build` подготавливают локальные файлы MapLibre в `cms/public/vendor/maplibre/<version>`. Нельзя включать ESM-движок напрямую в webpack: это меняет `import.meta.url` его worker. Версии зависимостей в корневом и CMS `package.json` должны совпадать. Публичная сборка размещает тот же комплект в `dist/vendor`, который обслуживает nginx.

Проверки: `npm run test:admin --prefix cms`, `npm run test:map`, `npm run test:map:renderer`, `npm run lint`, `npm run typecheck`, `npm run cms:build`. Тест админки проверяет сохранение отверстий и частей зданий, неизменяемость снимков, преобразование групп, связанные входы и маршруты через общий алгоритм.
