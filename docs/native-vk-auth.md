# Вход VK в Android

Интерфейс Улетая — React Native. Вход реализован нативным VK ID SDK 2.7.3 через локальный Expo-модуль `modules/uletay-vk-auth`. SDK предпочитает установленное приложение VK (`useOAuthProviderIfPossible=true`). Мини-приложение не используется. Запрошенные разрешения пусты: `phone`, контакты и сообщения VK не запрашиваются.

Для реального входа нужна настройка Android в кабинете VK ID: пакет `ru.uletay.app`, сертификат соответствующей сборки и защищённый ключ **VK ID**, не сервисный ключ API. Ключ в репозиторий и логи не записывать.

Локальная сборка читает игнорируемый Git файл `credentials/vk-native.properties`:

```properties
clientId=ID_ANDROID_ПРИЛОЖЕНИЯ_VK_ID
clientSecret=ЗАЩИЩЕННЫЙ_КЛЮЧ_VK_ID
```

Также поддерживаются переменные сборки `VK_NATIVE_APP_ID` и `VK_NATIVE_CLIENT_SECRET`. Серверу нужен такой же `VK_NATIVE_APP_ID`. Возврат SDK: `vk{clientId}://vk.ru/blank.html`.

Android-клиент `54911793` подключён отдельно от веб-клиента `54857258`. Реквизиты сохранены в игнорируемых файлах `credentials/`; локальная CMS использует `VK_NATIVE_APP_READY=1`. Сервисный ключ не передаётся в приложение и не используется вместо защищённого ключа VK ID. `apps.get` для нового сервисного ключа возвращает ошибку 1051; это не является проверкой авторизации SDK.

SHA-1 текущей локальной тестовой подписи: `5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25`. У выпуска будет свой сертификат.

PKCE verifier хранится на сервере. Приложение получает только state, challenge и отдельный секрет сеанса. Код из SDK обменивается сервером, а учётная запись определяется ответом VK. Нативная сессия хранится в системном защищённом хранилище Expo SecureStore. Переустановка тестового APK поверх существующего сохраняет избранное и настройки.

Схема БД дополняется через штатную миграцию CMS (`chat_native_auth`). Автотест `cms/scripts/test-native-chat-auth.ts` проверяет отсутствие phone scope, PKCE, чужой секрет, однократность результата и восстановление сессии. Он допускает только локальную базу `uletay_web_design:3352`.

Документация SDK: https://github.com/VKCOM/vkid-android-sdk

Фактический вход через установленное приложение VK пока не проверен: в тестовом эмуляторе VK не установлен. Доступ к кабинету VK ID через автоматизированный браузер заблокирован политикой безопасности; обход этого ограничения не выполнялся.
