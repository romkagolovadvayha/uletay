# Android 1.0.14

Продолжение исправлений по [отчёту Google Play для 1.0.13](./1.0.13-play-review.md).

В expo-audio прямая сетевая загрузка и `BitmapFactory.decodeStream` для обложек
радио заменены загрузчиком Glide 5.0.5. Изображение ограничивается 512 × 512,
пропорции сохраняются. Работают кеширование, тайм-аут и отмена запроса.
Уведомление получает собственную копию пикселей, которую Glide не переиспользует.
Это исправляет конкретный путь `fj.c0.invokeSuspend` из предыдущего отчёта;
предупреждения о декодерах внутри Glide/Fresco могут остаться.

Патч воспроизводится через postinstall и контролирует версию expo-audio.
В package.json задан `expo.autolinking.android.buildFromSource: ["expo-audio"]`:
по умолчанию SDK 57 берёт готовый AAR, который не включает изменения исходников.
Проверка конфигурации запускает настоящий resolver Expo Autolinking и проверяет
это исключение. В готовом AAB дополнительно проверяется наличие нового загрузчика.
Expo 57 / React Native 0.86 / AGP 8.13.2 сохранены. Оптимизация R8 и ресурсов
включена. Обновление AGP 9 и оставшиеся библиотечные Window API не закрыты.

## Проверки исходного кода

- Четыре теста Kotlin/Robolectric на API 35 прошли: большие альбомные и
  портретные изображения, владение Bitmap после освобождения кеша, повторная
  загрузка из кеша, HTTP-ошибка и быстрая отмена медленного запроса.
- Отчёт: `release-archive/1.0.14/qa/artwork-tests.xml`.
- TypeScript, ESLint и проверка совместимости версий Expo прошли.
- Повторное применение патча прошло; настройки R8 проверены тестом config plugin.

## Проверки готовых пакетов

В карте R8 AAB присутствуют встроенные методы `NotificationArtworkLoader.load`
и `load$lambda$0`: исправление действительно включено в пакет. В журнале обеих
сборок есть `:expo-audio:compileReleaseKotlin`. Первые попытки №34/35 были
отменены после обнаружения подстановки готового AAR; в магазины они не отправлялись.

Подписи проверены. Сертификат RuStore совпадает с 1.0.13. Все 50 ELF64-библиотек
в каждом пакете поддерживают выравнивание 16 КБ; APK также прошёл zipalign.
Сохранены minSdk 24 и targetSdk 36. Проверены полный режим R8 8.13.19,
оптимизация кода и ресурсов в AAB; в APK подтверждён финальный DEX-маркер R8.
Проверены конфигурация и публичный конструктор RuStore Push, отсутствие ранее
исключённых разрешений. В AAB остаются ссылки на три устаревших метода Window.

На Android 15 проверена чистая установка APK, полученного из AAB №36 и подписанного
отдельным тестовым ключом. В Google загружен исходный AAB. На Android 16 проверено
обновление подписанного RuStore APK №33 → №37. Сохранились первоначальное время
установки, разрешение уведомлений и один избранный радиотрек.

На обоих эмуляторах прошли запуск, радио (MediaSession PLAYING), воспроизведение
в фоне, возврат и пауза. Проверены снимки главной и радио с обложкой SELLOUT;
в уведомлениях присутствует Bitmap. Четыре просмотренных снимка связаны хешами
с соответствующими пакетами в `visual-review.json`. Физические устройства и
звучание через динамик не проверялись: эмуляторы работают без аудиовыхода.

Первый запуск теста на Android 15 перекрыл системный диалог System UI. Результат
сохранён отдельно; после закрытия диалога проверка прошла. Первоначальный скрипт
радио ожидал числовой формат dumpsys, хотя Android выдаёт `PLAYING(3)`; формат
проверки исправлен, повторный прогон прошёл. Приложение из-за этого не менялось.
Локальная интеграционная сборка остановлена из-за повреждённого кеша Gradle;
чистые сборки EAS успешно скомпилировали исправленный модуль.

Известное до этого выпуска отсутствие названий в отдельных строках истории и
избранного радио не исправлялось. Проверка сохранности избранного не означает
проверку всей вёрстки этих списков.
