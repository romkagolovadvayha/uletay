## Изменения

Джинглы радио отображаются отдельно от песен, используют название и логотип из эфира,
исключены из избранного, очереди и предыдущей песни. Данные эфира обновляются раз в 3 секунды.
Выпуск собран из текущей рабочей копии; 241 файл исходников сохранён с SHA-256 в архиве выпуска.

## Проверки

- TypeScript, ESLint, семь тестов радио и настройки Android/RuStore Push прошли.
- Оба готовых пакета содержат код джинглов и исправленный модуль expo-audio.
- Проверены подписи, версия, R8 и 50 нативных ELF64-библиотек в каждом пакете на поддержку 16 КБ.
- RuStore APK подписан тем же сертификатом, что 1.0.14; новых исключённых разрешений нет.
- На эмуляторе Android 15 оба пакета прошли запуск, радио, воспроизведение в фоне,
  возвращение в приложение и остановку. Просмотрены главная и радио каждого варианта.
- RuStore: обновление 37 → 39 сохранило время первоначальной установки и разрешение уведомлений.

Проверки Google выполнялись на APK из исходного AAB с отдельной тестовой подписью;
в магазин отправлен исходный AAB. Физические устройства и звучание через динамик не проверялись.
Параллельный запуск двух эмуляторов был остановлен из-за памяти компьютера; проверки выполнены
последовательно. Старый скрипт ожидал кнопку «Пауза»; после сверки с текущим интерфейсом
проверка использует «Остановить радио» и успешно завершилась.

Зависимости совпадают с 1.0.14. Expo сообщает о доступных обновлениях SDK 57;
для этого выпуска сохранён прежний lockfile зависимостей с новым номером приложения.
Ранее известные ссылки библиотек на устаревшие Window API остались; AGP 8.13.2 и R8 8.13.19.
