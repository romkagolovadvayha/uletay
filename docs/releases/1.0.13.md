# Android 1.0.13

Исправления по рекомендациям Google Play для версии 1.0.12 (29).

## Google Play

Сборка **1.0.13 (32)** загружена в рабочий трек `production`, проверена Google API и отправлена на модерацию с полным развёртыванием после одобрения. Подтверждённое состояние: **`RELEASE_LIFECYCLE_STATE_IN_REVIEW`**. Пока проверка не завершена, опубликованной остаётся 1.0.12 (29).

[Обзор публикации в Google Play Console](https://play.google.com/console/u/0/developers/9149396433864811864/app/4973903333594851717/publishing). Ответы загрузки, фиксации выпуска и проверки статуса сохранены в `release-archive/1.0.13/play-*.json`. Отправлен именно проверенный AAB с SHA-256 ниже.

## Изменения

- Expo SDK 57 обновлён до 57.0.23; совместимые обновления build-properties, location и notifications.
- AGP 8.12.0 → 8.13.2. Используется `proguard-android-optimize.txt`: предыдущий шаблон включал `-dontoptimize`, несмотря на `minifyEnabled=true`.
- Включены полный режим R8 и `android.r8.optimizedResourceShrinking`. Настройки закреплены в Expo config plugin, применяются при чистом prebuild и сборке EAS.
- Миниатюры артистов и фудкорта запрашивают RGB-декодирование вместо ARGB; Glide сохраняет поддержку прозрачности при необходимости. Уменьшение до размера контейнера и дисковый кеш заданы явно, `recyclingKey` сбрасывает старое изображение при смене источника. Большие фотографии сохраняют ARGB.
- Установлен `expo-system-ui`, чтобы Android действительно применял уже заданную тёмную тему. Чёрный корневой фон рисуется под прозрачными системными панелями. Edge-to-edge явно включён, приложение использует safe-area-context и не задаёт цвет панелей через устаревшие JS API.

## Ограничения рекомендаций Google Play

Нельзя считать все три предупреждения устранёнными только по настройкам проекта.

- **AGP 9:** Expo SDK 57 / React Native 0.86 официально его не поддерживают. Разработчик Expo подтвердил, что поддержка требует SDK 58. Вместо принудительной несовместимой миграции используется AGP 8.13.2 с явным включением оптимизированного удаления ресурсов. [Ответ Expo](https://github.com/expo/expo/issues/49550), [оптимизация R8](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization).
- **Window API:** React Native и AndroidX содержат старые вызовы для работы системных панелей, в том числе на старых Android. Наличие ссылок проверяется в DEX готового AAB; их отсутствие не обещается. Проверка интерфейса на Android 15/16 подтверждает поведение, но не удаляет библиотечные ссылки из бинарника.
- **Изображения:** интерфейс использует `expo-image`, который работает через Glide на Android. Однако повторный отчёт для 1.0.13 выявил отдельную прямую загрузку обложек уведомления внутри `expo-audio`; считать все замечания только особенностью сканера было бы неверно. Подробная расшифровка — [повторная проверка 1.0.13](./1.0.13-play-review.md). Флаг `decodeFormat` — предпочтение, фактический формат выбирает декодер. Численное снижение памяти без отдельного профилирования не заявляется. [Документация Expo Image SDK 57](https://docs.expo.dev/versions/v57.0.0/sdk/image/).

## Проверки

Готовая сборка: **1.0.13 (32)**, [EAS](https://expo.dev/accounts/romkadvayhas-team/projects/romkadvayha/builds/03e30041-4d57-4627-977e-22783316ebbd).

Проверка встроенного `BUNDLE-METADATA/com.android.tools/r8.json` подтвердила AGP 8.13.2 / R8 8.13.19, оптимизацию кода, полный режим и оптимизированное удаление ресурсов. DEX: 13 973 212 → 9 379 928 байт (**−32,9%**). Размер AAB: 94 089 531 → 93 665 604 байт. Это измерение размера кода, а не потребления RAM.

Все 50 библиотек ELF64 прошли проверку выравнивания для страниц 16 КБ. Подпись AAB проверена. Минимальный Android API остался 24. В DEX остаются ссылки на все три указанных Window API: предупреждение по устаревшим API не закрыто.

SHA-256: `2a62e053f8557defa2b174c1b2a6e1b061e4304dc9b8f61071d7c2a9c421989c`.

Пройдены TypeScript, ESLint, Expo Doctor (21/21), проверка конфигурации push и тесты prebuild. APK получен из этого AAB через bundletool и подписан отдельным локальным ключом только для тестов. В магазин отправляется исходный AAB с ключом выпуска.

На эмуляторах Android 15 (API 35) и Android 16 (API 36), x86_64, проверены холодный запуск, карта, хедлайнеры, фудкорт, экран радио, возврат из фона, жестовая и трёхкнопочная навигация. Проверены снимки экранов, состояние процесса и журналы ошибок. На Android 15 автоматическое ожидание неподвижного экрана мешало прочитать анимированную главную; использован режим `--visual-review` с отдельной проверкой снимка. Аналогично проверены снимки после переключения режима навигации; их SHA-256 сохранены в `qa/visual-review.json`. Первоначальные системные ANR эмуляторов относятся к их загрузке за полчаса до установки приложения; журналы сохранены отдельно. Физические устройства не проверялись.

Проверка настроек prebuild: `node scripts/test-android-release-config.mjs`.
Проверка R8 непосредственно внутри AAB: `python scripts/check-android-bundle.py app.aab report.json --require-optimized`.
Запуск на устройстве: `npm run test:android-startup -- --serial emulator-5580 --apk app.apk`.

Файлы выпуска и результаты проверки сохраняются в `release-archive/1.0.13/`.

Сборка загружена и отправлена на модерацию. Подтверждённое состояние API: **MODERATION**, версия RuStore **2064829645**. Установлены автоматическая публикация после одобрения (`INSTANTLY`) и распространение на 100% пользователей. [Сборка EAS](https://expo.dev/accounts/romkadvayhas-team/projects/romkadvayha/builds/bdb3705e-6ebb-4f78-84d2-a0484526f3b9).

APK: `release-archive/1.0.13/builds/uletay-1.0.13-33.apk`, SHA-256: `1a2e31bf3326876b77583b0faa56631cab6cdb7bdaed29a5fd3b5b68b0bbfbca`. Подпись совпадает с RuStore 1.0.12 (31); APK прошёл apksigner и zipalign для страниц 16 КБ. Все 50 ELF64-библиотек прошли проверку сегментов. Подтверждены AGP 8.13.2, финальный DEX-маркер R8 8.13.19 в полном режиме, minSdk 24, targetSdk 36, конфигурация RuStore Push и сохранность класса и конструктора RuStorePushClientParams.

На эмуляторе Android 15 проверена чистая установка, на Android 16 — обновление 1.0.12 (31) до 1.0.13 (33). После обновления сохранились время первоначальной установки, разрешение уведомлений и один избранный радиотрек. На обоих эмуляторах проверены запуск, карта, фотографии артистов, фудкорт, экран радио, возврат из фона, жестовая и трёхкнопочная навигация. Падений в журналах проверок нет. Для анимированной главной просмотрены снимки; их хеши сохранены в `rustore/qa/visual-review.json`.

Прямое переключение системного overlay через ADB при приложении в фокусе давало неполные кадры; они сохранены отдельно в `foreground-overlay-switch`. Повторная проверка через уход приложения в фон, переключение режима и возврат дала полные кадры на обеих версиях Android. Это наблюдение не подтверждает поведение на физических устройствах.

Отдельное замечание: на Android 16 в списках истории и избранного радио не отображались названия треков, хотя кнопки и счётчик избранного видны. Такое же отсутствие названий зафиксировано в UI-дереве 1.0.12 до обновления. Проверка сохранности избранного не считается проверкой корректности этой вёрстки; дефект остаётся для отдельного исправления. Доставка push и воспроизведение аудио в этом прогоне не проверялись.
