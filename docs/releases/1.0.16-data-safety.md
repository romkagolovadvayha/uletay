# Google Play 1.0.16 — исправление декларации данных

28 сентября 2026 года Google отклонил 1.0.15 (38): в форме «Безопасность данных»
не были заявлены «Идентификаторы устройства или другие идентификаторы».
В Console ранее был выбран ответ «Нет» на вопрос о сборе и передаче данных.
API подтвердил `RELEASE_LIFECYCLE_STATE_NOT_APPROVED`; опубликованной оставалась 1.0.14 (36).

## Фактическая обработка

- `src/utils/remotePushNotifications.ts` получает Expo Push Token и отправляет его,
  платформу устройства и HTTP User-Agent на `/api/push/subscribe`.
  Google Play использует Firebase Messaging и Firebase Installations, включая FID.
  В конфигурации нет отключения автоматической инициализации Firebase, поэтому
  сбор идентификаторов заявлен обязательным, не временным, для функций приложения
  и сообщений разработчика. Expo/Firebase выступают поставщиками доставки push.
- `src/utils/map/combinedRoute.ts` передаёт координаты во внешнюю маршрутизацию,
  когда пользователь строит маршрут вне территории фестиваля. Заявлены сбор
  и передача точного/приблизительного местоположения, необязательные, для работы
  приложения. Временная обработка не заявлена: координаты присутствуют в URL,
  которые могут попадать в серверные журналы.
- Аккаунтов, рекламы и пользовательской аналитики в приложении нет.
  Локальные избранное и напоминания мобильного приложения не объявлены сетевым сбором.

## Исправления

- Декларация загружена через `applications.dataSafety`; API вернул успех.
  В интерфейсе дополнен ответ «Нет» о входе с внешними аккаунтами, отсутствующий
  в старом CSV-шаблоне Google. Итоговая форма сохранена и добавлена в обзор публикации.
- Политика описывает идентификаторы, push-провайдеров, передачу координат,
  хранение неактивных подписок и обращение для удаления данных.
- Перед включением push и построением внешнего маршрута добавлены пояснения.
- Публичная страница `/legal` формируется из того же `LEGAL_SECTIONS`, доступна
  без JavaScript. Она не заменяется старым кешированным бандлом приложения.
  На сервер атомарно загружен только `dist/legal/index.html`, прежний файл сохранён.
- Номер приложения — 1.0.16, Android versionCode — 40.

## Сборка и проверки

Бесплатный лимит EAS исчерпан до 1 октября: запрос сборки зарезервировал код 40,
но облачная сборка не была создана. Используется локальная release-сборка Gradle
после Expo SDK 57 prebuild и прежний ключ загрузки, полученный из EAS.
SHA-256 сертификата совпадает с AAB 38:
`98:DC:3A:9C:E3:85:2C:FE:28:06:8A:B9:E5:D3:C1:C1:F6:DD:24:F7:6D:5E:3E:6D:E7:C8:31:7B:80:7A:7D:F8`.

TypeScript, ESLint изменённых компонентов, проверки конфигурации Android/RuStore
и проверка SEO-документов прошли. Публичная политика проверена в браузере.
Архив содержит 242 файла исходников с SHA-256. От предыдущего выпуска отличаются
только версия, тексты раскрытия данных и генератор публичной политики.

Локальная release-сборка завершилась успешно: 699 задач, 29 минут 46 секунд.
Первая попытка остановилась из-за нехватки памяти; повторная выполнена с одним
Gradle worker, heap 3 ГБ и компилятором Kotlin в основном процессе.

Проверки подписанного AAB прошли:

- `jarsigner` и `bundletool validate`, совпадение сертификата с предыдущим выпуском;
- версия 1.0.16 (40), пакет `ru.uletay.app`, production API;
- R8 full mode и optimized resource shrinking;
- совместимость 50 ELF64-библиотек с выравниванием 16 КБ;
- отсутствие разрешений микрофона, рекламного идентификатора и компонентов RuStore;
- наличие обновлённой политики, пояснений о push и координатах в Hermes-бандле;
- сохранение исправления загрузки обложек радио из предыдущей версии.

Физический Android и эмулятор не были доступны: запуск на устройстве в этой
сессии не проверялся. Временные копии ключа загрузки удалены после проверки подписи.

## Отправка

28 сентября 2026 года AAB загружен и production-релиз сохранён через Google Play API.
Размер: 93 720 035 байт. SHA-256:
`158496c3f962a29490d0eea2ed762d3e3a53fd0ab3b8dab11d33d90f9536f2d3`.
API подтвердил номер 40 и совпадение SHA-256 загруженного файла.

После предыдущего отказа API потребовал `changesNotSentForReview=true` и явную
отправку из Play Console. Релиз сохранён с этим параметром; в Console отправлены
оба изменения: **1.0.16** и **Безопасность данных**.

Повторный запрос `/tracks/production/releases` подтвердил
`RELEASE_LIFECYCLE_STATE_IN_REVIEW` для 1.0.16 (40). Console также показывает
оба изменения в разделе «Изменения на проверке»; начальная автоматическая
проверка Google на тот момент ещё выполнялась. Опубликованной остаётся 1.0.14 (36).
Управляемая публикация включена: после одобрения потребуется публикация в Console.

Архив исходников, сборки и ответов API: `release-archive/1.0.16/`.
Результаты проверки пакета — `qa/`; приём файла — `play-bundle.json`,
сохранение релиза — `play-committed.json`, подтверждение модерации — `play-status.json`.
