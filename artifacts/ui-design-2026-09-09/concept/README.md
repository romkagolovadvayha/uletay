# Улетай · В ритме поля

Интерактивный дизайн-концепт. Откройте `index.html` в браузере или запустите из корня проекта:

```powershell
node artifacts/ui-design-2026-09-09/concept/preview.cjs
```

Адрес: [localhost:4397](http://localhost:4397/). Для другого порта задайте `CONCEPT_PORT`.

Проверьте переключатель «До фестиваля / На фестивале», программу по дням и сценам, сердца и «Мой план», поиск артистов, карточки, точки на схеме, демо-плеер и кнопку CMS. В CMS можно изменить запись, увидеть предпросмотр и сохранить её в памяти вкладки. Escape закрывает карточку. Motion выключается вручную и по настройке уменьшения движения в системе.

Данные, расстояния, цены, статусы загрузки и расписание — демонстрационные. Фото взяты из существующего архива проекта. Это не анонс состава 2027. Радио без звука; карта условная; запросы к геолокации и API, звонки, push и публикации не выполняются. Сердца хранятся только в отдельном ключе браузера `uletay-concept-favorites`.

Макет CMS детально показывает редактор программы. Остальные разделы разобраны в соседних `AUDIT.md` и `DESIGN.md`. Действующий код приложения и CMS этим концептом не заменён.
