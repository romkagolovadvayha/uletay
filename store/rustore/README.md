# RuStore

Карточка приложения `ru.uletay.app` использует русское описание из
`ru-RU/listing.json` и иконку `ru-RU/icon.png` (512 × 512).

Шесть вертикальных изображений совпадают с Google Play. Источники, в порядке
показа, находятся в `../google-play/ru-RU/graphics/`:

1. `01-lineup.png` — хедлайнеры.
2. `02-chat.png` — общий чат.
3. `03-wishes.png` — голосование.
4. `04-artist.png` — артист и треки.
5. `05-map.png` — карта фестиваля.
6. `06-schedule.png` — расписание и ползунок времени.

Сборка RuStore использует профиль `rustore`, прежний сертификат подписи и
RuStore Push SDK. APK должен иметь `versionCode` выше предыдущего релиза,
быть недоступным для отладки и сохранять native-клиент VK ID `54911793`.
Ключи публикации и APK хранятся вне Git.

При публикации проверять чтением из RuStore название, описание, порядок и
содержимое всех шести изображений, номер APK и статус модерации. Настройка
`INSTANTLY` публикует одобренную версию автоматически.
